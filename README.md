# Next.js e React - Unica Task — Gestor de Projetos Kanban

Aplicação fullstack de gerenciamento de tarefas em formato Kanban, desenvolvida para atender uma demanda real de um setor administrativo de um plano de saúde que não possuía orçamento para ferramentas como Trello ou Monday.

O sistema permite organizar projetos e atividades por meio de quadros, listas e cartões, simulando um fluxo de trabalho utilizado em ambientes corporativos.

---

## Motivação

Este projeto surgiu a partir de uma necessidade prática: criar uma alternativa funcional para organização de tarefas sem depender de soluções pagas. A aplicação foi pensada para resolver um problema real, com foco em usabilidade, persistência de dados e boa arquitetura.

---

## Funcionalidades

- Criação e gerenciamento de quadros de projetos  
- Organização de tarefas em listas e cartões  
- Fluxo Kanban para acompanhamento de atividades  
- Autenticação de usuários  
- Persistência de dados em banco  
- Interface responsiva  

---

## Tecnologias Utilizadas

- Next.js  
- React  
- TypeScript  
- Tailwind CSS  
- Prisma  
- Appwrite / Clerk  

---

## Conceitos Aplicados

- Arquitetura de componentes reutilizáveis  
- Gerenciamento de estado no React  
- CRUD completo (Create, Read, Update, Delete)  
- Integração entre frontend e backend  
- Boas práticas de organização de código  
- Desenvolvimento voltado a cenário real de uso
